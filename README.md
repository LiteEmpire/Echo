# Lite AI

A standalone home for Lite AI, separate from the portfolio repository.

## Current status

- Responsive chat-style front-end is in `index.html`.
- This is currently a front-end demo; it does **not** generate real AI answers yet.
- Tripo is intended for 3D generation, not general-purpose chat.
- To enable real answers, connect a chat-model API through a secure backend or serverless function.
- Never place private API keys in browser-side HTML or JavaScript.

## Publish with GitHub Pages

1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. After GitHub finishes publishing, the site should be available at `https://liteempire.github.io/Echo/`.

Repository: https://github.com/LiteEmpire/Echo
